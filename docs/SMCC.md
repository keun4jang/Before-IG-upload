# SMCC 운영 검수 모드

서울모닝커피클럽 운영 검수 도구. 신청 원본(Google Sheet) → 정답 생성 → 카드 검수 → 장소 교차확인.

경로: `/smcc`

## 지원 시트

| 프로그램 | 언어 | 시트 |
| --- | --- | --- |
| Espresso Run | KR | 신청 스프레드시트 |
| Book Dive | KR/EN | 신청 스프레드시트 |
| Daily Coffee Chat (KR) | KR | 신청 스프레드시트 |
| Daily Coffee Chat (EN) | EN | 신청 스프레드시트 |

URL/gid 는 `packages/shared/src/smcc/constants.ts` 의 `SHEET_SOURCES` 에 정의.

## 사용 방법

1. 시트 선택 → 행 목록 로드 (실패 시 예시 데이터로 fallback)
2. 행 선택 → **원본 / 정규화 / 정답** 확인
3. 카드 텍스트 붙여넣기(또는 이미지 첨부 후 수동 입력)
4. **오류 / 경고 / 확인 필요** 이슈 확인 → 수정
5. **장소 확인**으로 카페/주소 교차확인
6. 상태가 "완료 가능"이면 제작/업로드

작업(카드 텍스트·처리한 이슈·메모)은 브라우저에 자동 저장되어 다시 열면 유지됩니다.

## 무료 모드에서 가능한 것

- 공개 Google Sheet 불러오기 (CSV export)
- 정답 텍스트 생성 + 복사 / MD·JSON 내보내기
- 오타 없이 **날짜/요일·시간·참가비·언어·프로그램 규칙** 검수 (키 불필요)
- OpenStreetMap(Nominatim) 무료 장소 교차확인 + 지도/검색 링크

유료 provider(Google Vision·Maps·LLM 등)는 optional 이며 없어도 핵심 플로우가 동작합니다.

## 검수 규칙 (요약)

- **언어**: KR 카드는 한글, EN 카드는 영어. 카페명/호스트/고유명사는 원문 유지. EN 카드에 한글 프로그램명 → 오류.
- **날짜**: 실제 날짜의 요일과 카드 요일 불일치 → 오류.
- **시간**: 시작시간 + 프로그램 소요시간(에스프레소런 2h, 북다이브 2h, DCC 1h, Rave 3h, Glow Up 1.5h)으로 종료시간 자동 계산 후 비교.
- **참가비**: 무료 = `1인 1잔` / `Min. 1 Drink`("Order 1 Drink" 금지). 유료 = 에스프레소런 KR 카페1곳 15,000원·2곳+ 20,000원, EN $30 / 북다이브 EN $25. 잘못된 통화(15000달러, 20,000$, KRW 15,000 등) → 오류.
- **추가정보**: 북다이브는 Needs·책 안내, 에스프레소런은 거리·코스 필수.
- **원본 대비**: 정답 값이 카드에 없으면 불일치로 표시.
- **장소**: 외부 후보와 토큰 유사도로 일치 가능성 판단(단정 금지, confidence·링크 제공).

## 장소 검증 방식

- 기본: OpenStreetMap Nominatim(무료). 후보 displayName 과 카페명 토큰 겹침으로 판정.
- 판정: 일치 가능성 높음 / 불일치 가능성 / 검증 불가 / 수동 확인.
- 결과는 참고용이며 지도·웹검색 링크를 함께 제공.

## Known limitations

- 시트 컬럼은 헤더 키워드로 매핑 — 헤더가 크게 바뀌면 매핑 조정 필요.
- 연도 없는 날짜는 기준일 기준으로 추정.
- 카드 텍스트는 OCR 자동화 없이 수동 입력 우선(브라우저 OCR은 optional).
- 외부(Nominatim/Sheets)는 네트워크/차단 시 예시·수동으로 degrade.

## 새 프로그램/시트 추가

1. `program-config.ts` 에 프로그램 추가(소요시간·참가비·추가정보)
2. `constants.ts` `SHEET_SOURCES` 에 시트 등록
3. `normalizers/` 에 시트 어댑터 추가 후 `engine/normalize-event.ts` 에 연결
4. 필요 시 `validators/` 규칙 보강 + `fixtures/` 예시 추가
